# September 30, 2026 release

- Paper title, seven-author order, affiliation, abstract, and citation follow
  the supplied September 30 manuscript. The latest PDF is hosted on the
  project page alongside the existing arXiv link.
- The framework is the exact vector graphic embedded as Figure 4 on page 6.
  Its decoded content stream and complete PDF resource graph were matched
  against the original figure source before generating the web image.
- The data pipeline is the original Figure 3 from page 5, with its content
  stream and resource graph preserved. Both figures have vector PDF and PNG assets.
- The complete author-provided inference export is included: Flash, multistep
  OmniVR, LTX core, and the upstream LTX inference pipelines.
- Release integration bundles the optional legacy TAEHV helper and replaces
  its external `echo_sr` import. The default multistep decoder is the full
  LTX VAE. Portable root and legacy launchers use the bundled packages.
- The old `pip install -e .` / external training-checkout workflow is replaced
  by `pip install -r requirements.txt` and direct repository entry points.
- Public model files still contain the two multistep checkpoints and the
  optional legacy decoder. Flash LoRA, Turbo VAE, and prompt-cache artifacts
  require a separate compatible release; no experimental training checkpoint
  is substituted for them.
- The supplied Flash entry point processes one window with full-resolution
  condition latents. Reduced-resolution condition injection and automatic
  cross-window anchoring shown in the paper are not exposed in this export.
- The README includes the main-text RTN, OmniVRBench, and human-preference
  results (Tables 1–4).

## Validation

Python 3.12.12, PyTorch 2.9.1+cu128, and Transformers 4.57.6 were used
for standalone imports and all five CLI entry points. The checks ran from
an unrelated working directory with external training modules blocked.
Root, package, and legacy launchers expose matching command interfaces.
Prompt-cache routing and legacy environment-variable arguments were checked.

All 148 Python files passed syntax parsing. The website's existing media
player scripts are unchanged; local links, JavaScript syntax, paper metadata,
and the unchanged manuscript hash were checked. Validation did not run a
new GPU restoration benchmark or perform visual review of video content.
