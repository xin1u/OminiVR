# Project link badges

The compact, two-part badge style follows the links in
[UltraFlash](https://github.com/xin1u/UltraFlash): a red paper badge, green project
page badge, and blue 🤗 Hugging Face model badge.

These SVGs use the official [Shields.io badge-maker](https://github.com/badges/shields/tree/master/badge-maker)
renderer (version 6.0.0, flat style, 20 px height). The renderer's MIT license
is retained in [LICENSE-badge-maker](LICENSE-badge-maker).
The arXiv and GitHub logo paths come from
[Simple Icons](https://github.com/simple-icons/simple-icons), under CC0-1.0.
